# NeoMantle

An unofficial **Minecraft 1.21.1 NeoForge** port of **Mantle** by SlimeKnights.

Mantle is a library/dependency mod & is **required by [Neo Tinkers' Construct](https://github.com/vancevoj/NeoTinkersConstruct)** and does little on its own.

Full credit for the mod goes to SlimeKnights. I take no credit for any of the original work. SlimeKnights have stated they do not want a 1.21.1 NeoForge fork; myself and others wanted one anyway, so I made this (sorry). This project is **not official** and is in no way endorsed by or affiliated with SlimeKnights. Use it at your own discretion.
